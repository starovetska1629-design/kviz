# Квіз-Сцена

Живий квіз для залу. Ведучий показує питання на великому екрані. Гравці заходять з телефонів за PIN-кодом або QR-кодом, без реєстрації. Що швидше правильна відповідь, то більше балів: від 1000 до 500.

## Як викласти в інтернет (безкоштовно, приблизно 10 хвилин)

### 1. Завантажити файли на GitHub
1. Зареєструйтеся на https://github.com, якщо ще не маєте акаунта.
2. Угорі праворуч натисніть **+** → **New repository**.
3. Назва: `kviz`. Позначте **Public**. Натисніть **Create repository**.
4. На сторінці репозиторію натисніть посилання **uploading an existing file**.
5. Розпакуйте архів і перетягніть у вікно **весь вміст** папки `kviz`: `server.js`, `package.json`, `package-lock.json`, `README.md` і папку `public` (саму папку, а не окремі файли з неї).
6. Натисніть **Commit changes**.

### 2. Запустити на Render
1. Зайдіть на https://render.com і натисніть **Get Started**, потім увійдіть через **GitHub**.
2. Натисніть **New +** → **Web Service** і оберіть репозиторій `kviz`.
3. Заповніть поля:
   - **Language / Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
4. Натисніть **Create Web Service** і зачекайте 2–3 хвилини, поки статус стане **Live**.
5. Угорі буде адреса на кшталт `https://kviz-xxxx.onrender.com`. Це ваш сайт.

## Як грати
- **Ведучий** відкриває `адреса/host` на ноутбуці, під'єднаному до проєктора. Там можна ввести питання (або вставити списком) і натиснути **«Створити гру»**.
- На екрані з'являються великий PIN і QR-код. **Гравці** сканують QR-код або відкривають `адреса` на телефоні, вводять PIN і своє ім'я.
- Ведучий натискає **«Почати гру»**. Далі можна керувати кнопками на екрані або клавішами пробіл / Enter.

## Раунди (кілька переможців)
- На сторінці питань угорі є блок **«Раунди»**. Кожен раунд — окремий набір питань зі своєю назвою (наприклад, «Про Олю», «Про Максима»).
- Після фіналу раунду натисніть **«Наступний раунд →»**. Гравці залишаються в грі, бали обнуляються, і в новому раунді буде свій переможець.
- У лобі раунд можна вибрати зі списку **«Раунд:»**.

## Загальний рейтинг
- Бали з усіх зіграних раундів сумуються. Кнопка **«Загальний рейтинг»** є на фіналі кожного раунду і в лобі.
- Якщо раунд зіграти повторно, у рейтинг піде його новий результат (а не сума двох).
- Гравець, який повернувся з іншого телефона під тим самим ім'ям, зберігає свої бали.
- **«Скинути рейтинг»** обнуляє загальні бали, щоб почати нову серію раундів.

## Важливо
- Безкоштовний сервер Render «засинає», якщо 15 хвилин ніхто не заходив. Перше відкриття після цього триває до хвилини. **Відкрийте сайт за 2–3 хвилини до гри.**
- Питання зберігаються в браузері ведучого. Щоб вони з'являлися на будь-якому пристрої, впишіть їх у файл `public/questions.js` (там є приклад формату з кількома раундами) і завантажте його на GitHub. Render оновить сайт сам.
- Якщо гравець випадково закрив сторінку, хай відкриє її знову: його повернуть у гру з тими самими балами.
- Не перезапускайте сервер під час гри: поточна гра зникне.
